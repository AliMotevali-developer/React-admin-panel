## 🇬🇧 English

A modern, responsive single-page application (SPA) designed for administration panels and content management. Built using **React 18** and **React Router DOM**, this dashboard demonstrates modular component design, stateful data manipulation (CRUD), dynamic modal handling, and simulated authentication flow.

### 🔑 Demo Credentials

### ✨ Key Features
- 📊 **Interactive Analytics Dashboard:** Real-time summary metric cards and recent listings overview.
- 📝 **Full CRUD Management:** Complete create, read, update, and delete flows for listings and users.
- 🔍 **Live Search & Status Filtering:** Instant client-side search and multi-state status filters.
- 🪟 **Reusable Modal System:** Reusable portal-like modal component for seamless form submissions.
- 📱 **Mobile-First Responsive Layout:** Custom responsive sidebar navigation with touch-friendly controls.
- 🔐 **Auth Flow Simulation:** Protected routes and session validation utilizing browser local storage.

### 🛠️ Tech Stack
- **Library:** React 18 (Hooks: `useState`, `useEffect`, `useLocation`, `useNavigate`)
- **Routing:** React Router v6
- **Icons:** React Icons (`FaBars`, `FaTimes`)
- **Styling:** Modular Pure CSS with responsive Flexbox & CSS Grid
